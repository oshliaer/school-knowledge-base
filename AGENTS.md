# AGENTS.md — конвенции репозитория

Правила уровня репозитория; предметные — в `<папка предмета>/AGENTS.md`
(они конкретнее и имеют приоритет). Технические детали — в
[CLAUDE.md](CLAUDE.md) и [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md);
не дублируй их, ссылайся.

## Предметы

Точные имена: `Английский язык`, `Вероятность и статистика 7-9` и `Физика 7` —
Markdown-колоды; `География мира` — CSV-колода. Не переименовывать и не
транслитерировать.

Markdown: `deck.yaml`, `decks/*.md`, `styles.css` при необходимости.
CSV: `deck.yaml`, `countries.csv`, `overrides.yaml`, `flags/`, `flags.csv`,
`styles.css`. Сборка — [scripts/md2anki.py](scripts/md2anki.py) и
[scripts/csv2anki.py](scripts/csv2anki.py); это разные конвейеры, команды — в
[CLAUDE.md](CLAUDE.md).

## Каркас карточек

Полный синтаксис — в [CLAUDE.md](CLAUDE.md), раздел «Формат карточек».
Каркас: frontmatter с `type`/`tags`; `id:` перед `##` (уникальный, неизменный);
разделитель карточек `---`; в `basic`/`basic-reversed` стороны разделяет `^^^`
(без него карточка пропускается); в `cloze` — `{{c1::...}}`, часть после `^^^`
уходит в Extra; имена файлов на русском с номером (`01-тема.md`); скриншоты не
вставляем, таблицы — HTML `<table>`; ответ не делаем сплошным жирным.

Типы карточек, отбор фактов, формулы, LaTeX и критерии ответа — в
`<папка предмета>/AGENTS.md`, не в корне.

## Изменения, версии и PR

- Одна ветка — одна тема; PR в `master` с описанием «что/зачем/как проверить»
  и ссылкой на issue.
- Пользовательские изменения — в [CHANGELOG.md](CHANGELOG.md) («Добавлено /
  Изменено / Исправлено»).
- `VERSION` описывает `master` и может опережать тег. Версию и changelog
  поднимают, когда накопились изменения; тег `v*` — отдельное решение о
  публикации, его ставит мейнтейнер после merge.
- CI: PR не собирается; merge в `master` даёт артефакт Actions; тег `v*`
  публикует `.apkg` в GitHub Release (подробности — в
  [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)).
- `dist/`, `.venv/`, `tmp/`, `.dsh/` не коммитим; `deck.yaml:id` не меняем
  после первого импорта в Anki.

## Предметные детали

- `Физика 7/AGENTS.md` — регламент редактора карточек по физике.
- Для остальных предметов отдельного файла пока нет.

Новый `<папка предмета>/AGENTS.md` — только после подтверждения папки и
предметных правил от пользователя. Не выводить правила одного предмета из
другого и не придумывать «по аналогии»; для математики — сначала
подтверждение, потом файл. Примеры карточек и формулировки не редактируем
«для красоты»: дословность важна.
